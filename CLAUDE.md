# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

`eugeo` ("Geografia europea") is a static, dependency-free geography quiz in **Italian**, aimed at learning Europe's main rivers, seas and mountain ranges. The player picks a card, taps the matching place on an SVG map of Europe, then presses **Verifica** to score. It is hosted on GitHub Pages from `main` / root (`.nojekyll` present) at the custom domain **eugeo.giar.dev**, which is set by the `CNAME` file (DNS: `CNAME eugeo → miguelgila.github.io`). Don't remove or rename `CNAME`, or the custom domain stops working. It is also an installable PWA via `manifest.webmanifest` (no service worker).

The footer credits Natural Earth (linked to naturalearthdata.com) and carries a plain Ko-fi donation link (`ko-fi.com/miguelgila`). Keep the link plain: no third-party widgets, scripts, analytics or cookies, since the audience is schoolchildren and the site currently needs no consent banner. Code is MIT (`LICENSE`); `data.js` is derived from Natural Earth (public domain) plus the CC0 `tools/handdrawn.geojson`, both in `DATA_LICENSE`.

The site has no build step, no package manager and no linter. The only tooling is the Python data pipeline in `tools/`, which has its own tests. Never hard-code user-facing text in `index.html`: add a key to every language in `i18n.js`. Never hand-edit `data.js`: change `tools/build_data.py` and rebuild.

It is a sibling of `chgeo` (Swiss geography) and deliberately keeps the same structure and naming, so changes can be ported between the two by reading the diff.

## Architecture

There are three site files plus the pipeline.

- **`i18n.js`**: `window.I18N`, with three parts:
  - `langs`: the list of `[code, name]` pairs. Only `['it', 'Italiano']` today.
  - `ui[lang][key]`: flat UI strings with `{0}`/`{1}` placeholders. Mode strings are keyed `mode.<id>.<label|tray|subtitle|what|help>`, and maps are keyed `map.<id>` and `map.<id>.title`.
  - `places[targetId][lang]`: place names keyed by the same target IDs as the game (`r:Reno`, `s:Egeo`, `m:Alpi`, and every `c:` country, ready for a future countries deck).

  Missing UI keys fall back to Italian, and missing places fall back to the name in `data.js`. When a language is added, it must define every UI key with the same placeholders, and a `places[id][lang]` entry for each target.

- **`data.js`**: generated by `tools/build_data.py`, assigned to `window.GEO`. **Do not hand-edit it.** Its shape:
  - `GEO.eu`: `w:1000, h:629`, `version{ne, built}` (`ne` maps each dataset's short name in `DATASETS` to its Natural Earth version)
  - `land[{d}]`: one background path; `countries[{id,name,iso,d,cx,cy}]` and `lakes[{name,d}]`: background
  - `rivers[{id,name,d,cx,cy}]` (13), `seas[{id,name,d,cx,cy,parent}]` (11), `ranges[{id,name,d,cx,cy}]` (12)
  - `cities[]`: empty; reserved for `{id:'t:…', name, cx, cy, capital, iso}`
  - `d` is an SVG path in canvas coordinates; `(cx, cy)` is the label/chip anchor.

- **`index.html`**: markup, CSS and one inline IIFE script. Its main parts:
  - **`MAPS`**: a single entry, `eu`. It exposes the `GEO.eu` layers (`land`, `countries`, `lakes`, `rivers`, `seas`, `ranges`, and `pins`, which is `[]` for now) and lists the `modes` (decks).
  - **Mode/deck**: `{id, kind, targets()}`; its labels come from `mode.<id>.*` in `i18n.js`. `kind` is one of `river | sea | zone | pin` and controls which SVG layer is clickable and coloured: `river` the rivers, `sea` the seas, `zone` the mountain ranges, `pin` the pins. `targets()` returns `{id, name, cx, cy}`. The decks are `rivers` (Fiumi), `seas` (Mari e oceani) and `ranges` (Catene montuose).
  - **Target ID convention**: target IDs must match the IDs that `buildSvg()` binds to click handlers. Prefixes: `r:` river, `s:` sea, `m:` mountain range, `c:` country (background today), `t:` town/city (reserved). River, sea and range IDs are derived from the **Italian names** in the pipeline's tables (country IDs from Natural Earth's `name_it`), so they are stable keys, not display text. Display names always go through `pn()`.
  - **The `parent` rule (seas)**: `s:Mediterraneo` is only the open-water remainder; `s:Ligure`, `s:Tirreno`, `s:Adriatico`, `s:Ionio` and `s:Egeo` are separate paths with `parent: 's:Mediterraneo'`. In `render()`, `seaStatus()` colours a sub-sea with its parent's placement when the sub-sea has no card of its own; its own placement wins. Only the parent's own `status()` counts towards the score. In `pickTarget()`, tapping such an inherited sub-sea with no card selected takes the parent's card back. The rule is generic, but only the Mediterranean has children.
  - **State `S`**: `{map, mode, order, selected, placed{targetId→cardId}, checked, names, view{z,cx,cy}}`. `fresh()` reshuffles the deck and turns `names` off. `setMap()` rebuilds the SVG. `setMode()` only re-renders.
  - **`buildSvg()`** runs once per map and creates the DOM nodes in drawing order: a background water `rect` (untargeted seas such as Marmara or the Barents Sea are just this), land, countries, lakes, seas, ranges, rivers, then the rivers' tap areas and the pins. Rivers get a second, invisible, wider `riverHit` path, and pins a transparent `pinHit` circle, as tap targets. `applyView()` sizes both in screen pixels.
  - **Order matters in `setMap()`**: call `buildSvg()`, then `render()`, then `applyView()`. `applyView()` reads `box.clientWidth`, which forces a style pass. If that runs before `render()` has set the fills, the new shapes get computed with no fill (black), and the `transition: fill` animates from black.
  - **`render()`** runs on every state change and recolours the existing nodes through `status()` (idle, placed, ok, bad or unplaced colours). Layers that are not the current deck's kind are muted or hidden and do not take taps (seas get `pointer-events: none`, ranges lose fill and stroke, river tap areas are hidden). It also rebuilds the card tray, progress, results and the "Da ripassare" error list. `renderChips()` draws HTML overlay labels at each target's `(cx, cy)`. After a check, wrong placements get red chips with the correct name. With `S.names` (the "Mostra nomi" toggle), every target gets a neutral `.chip.name` label, and the red chips stay on top.
  - **Zoom/pan** works by rewriting the SVG `viewBox` (`S.view`, zoom range 1–8). It supports pointer drag, two-finger pinch and ctrl/wheel. A drag sets `dragged` so that the pointer-up does not count as a pick.
  - The last selected map is persisted in `localStorage['eugeo.map']`.
  - **i18n**: `t(key, ...args)` returns UI strings, `pn(id, fallback)` returns place names, and `mt(k)` returns strings for the current mode. Static markup is translated through `data-i18n` (text) and `data-i18n-aria` (aria-label) attributes. The language is chosen by `?lang=xx`, then `localStorage['eugeo.lang']`, then Italian. The browser language is deliberately ignored, because the default is Italian by the owner's choice. The language `<select>` is hidden while `I18N.langs` has one entry, and the map nav while `MAPS` has one entry, so adding a language or map needs no extra UI work. `setLang()` re-translates without reshuffling.

- **`tools/`**: the data pipeline. Full documentation is in `tools/README.md`.
  - `build_data.py` downloads Natural Earth 1:10m shapefiles into `tools/cache/` (git-ignored), pre-clips them to `PRECLIP` in lon/lat, projects to EPSG:3035, simplifies, clips to `WINDOW` (lon −25..70, lat 33..72) and scales to the `W`×`H` canvas (1000×629) through `Fit`. Every feature goes through `feature_to_canvas()`. `build()` assembles `GEO.eu` and `write_data_js()` writes it.
  - The content lives in tables in `build_data.py`: `RIVERS` (Italian name ↔ NE `name_en`), `SEAS` (the merge table: NE polygon names unioned per target, plus `parent`), `RANGES` (NE region name, or `None` for a hand-drawn outline), and the `RIVER_ANCHORS`/`SEA_ANCHORS`/`RANGE_ANCHORS` label overrides tuned with `tools/preview.py`. The script raises `SystemExit` rather than writing a partial `data.js` when a table entry matches nothing.
  - `handdrawn.geojson`: the Apennines and Cantabrian Mountains, which Natural Earth lacks. CC0, typed in by hand, checked only against Natural Earth.
  - `build_cities()` is a stub returning `[]`; `tools/README.md` explains how to turn it into a capitals deck.

```sh
.venv/bin/python tools/build_data.py     # rebuild data.js
cd tools && ../.venv/bin/pytest          # pipeline tests
.venv/bin/python tools/preview.py        # writes tools/preview.svg for eye checks
```

Set up the venv with `python3 -m venv .venv && .venv/bin/pip install -r tools/requirements-dev.txt`.

## Adding a deck

Add a mode to `MAPS.eu.modes` in `index.html`, and its `mode.<id>.*` strings and place names to every language in `i18n.js`. Any new geometry must first be produced by `tools/build_data.py` into `data.js`, and must be wired into a layer of `MAPS.eu`, otherwise there will be no clickable element whose ID matches the target. A capitals deck uses `cities` → `pins` with `kind: 'pin'`. A countries deck needs topology-preserving simplification of the country layer first (see `tools/README.md`), and a new kind, since countries are background today.

## Do not

- Hand-edit `data.js`, or commit it without rebuilding from the script.
- Hard-code UI text in `index.html`.
- Remove or rename `CNAME`.
- Add third-party scripts, widgets, analytics or cookies. The only external resource is the Manrope stylesheet from Google Fonts, inherited from chgeo; don't add more.
- Use any data source other than Natural Earth and the CC0 `tools/handdrawn.geojson`; never trace outlines from other maps.
- Commit `.venv/`, `tools/cache/` or the preview outputs (all git-ignored).
- Add AI or co-author attribution lines to commits.
