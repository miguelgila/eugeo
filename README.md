# eugeo — Geografia europea

A small, dependency-free geography quiz in Italian for learning the main rivers, seas, mountain ranges, countries and capitals of Europe. Pick a card, tap the matching place on the map, then press **Verifica** to see what matched.

It is a single static page: `index.html` (markup, styles, logic), `i18n.js` (UI strings and place names per language) and `data.js` (map geometry, generated). Italian is the only language today; `i18n.js` is structured so more can be added, and the language selector appears as soon as there is more than one. No build step, no backend for the site itself.

## Decks

| Deck | Cards | Notes |
|---|---|---|
| Fiumi | 13 | Tago to Volga. Tap near the river line. |
| Mari e oceani | 11 | The Mediterranean contains the Ligurian, Tyrrhenian, Adriatic, Ionian and Aegean seas: placing *Mar Mediterraneo* on the open Mediterranean also colours those inner seas, unless one of them has its own card. The Caspian is in this deck. |
| Catene montuose | 12 | Drawn as translucent brown areas so country borders stay visible beneath. |
| Stati | 46 | Tap the country. The six microstates (Andorra, Liechtenstein, Malta, Monaco, San Marino, Vatican) also have a dot; on a phone, zoom in to tap them. |
| Capitali | 46 | The capitals of the same 46 countries, shown as dots after Verifica. Tap the country the capital belongs to. |

Countries outside the Stati deck, such as Turkey, the Caucasus and North Africa, are drawn as background only, for orientation.

## Run locally

Any static file server works, e.g.

```sh
python3 -m http.server 8000
```

then open <http://localhost:8000>.

## Hosting on GitHub Pages

Settings → Pages → *Deploy from a branch* → `main` / root. `.nojekyll` is present so the files are served as they are.

The site uses the custom domain `eugeo.giar.dev`: the `CNAME` file in the repo root contains it. At the DNS provider, add a `CNAME` record `eugeo` → `miguelgila.github.io`. GitHub provisions the TLS certificate automatically; tick *Enforce HTTPS* once it is issued.

The footer credits Natural Earth and has a plain Ko-fi link. There are no analytics, cookies or third-party scripts, because the audience is schoolchildren. The only external resource is the Manrope font stylesheet from Google Fonts.

## Data

All map geometry comes from [Natural Earth](https://www.naturalearthdata.com/) 1:10m (public domain), except two mountain ranges Natural Earth does not have:

- Land, country outlines and large lakes: `ne_10m_land`, `ne_10m_admin_0_countries`, `ne_10m_lakes`.
- Capitals: `ne_10m_populated_places_simple`.
- Rivers: `ne_10m_rivers_lake_centerlines`.
- Seas: `ne_10m_geography_marine_polys`, several polygons merged per sea.
- Mountain ranges: `ne_10m_geography_regions_polys`.
- Apennines and Cantabrian Mountains: hand-drawn in `tools/handdrawn.geojson`, released CC0.

Dataset versions are listed in [DATA_LICENSE](DATA_LICENSE).

## Regenerating the data

`data.js` is generated by `tools/build_data.py`; never edit it by hand. The script downloads the Natural Earth shapefiles into `tools/cache/` (git-ignored), projects them to ETRS89-LAEA Europe (EPSG:3035), simplifies, clips and writes SVG paths. Country borders are simplified together, so neighbours share one border line.

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-dev.txt
.venv/bin/python tools/build_data.py
cd tools && ../.venv/bin/pytest
```

See [tools/README.md](tools/README.md) for the details: name and merge tables, label anchors, the country roster and capitals, the preview script and how to add other cities.

## Adding a deck

Decks live in `MAPS.eu.modes` at the top of the script in `index.html`. A deck is a `mode` with an `id`, a `kind` (`river`, `sea`, `zone`, `country` or `pin`), an optional `dots` flag that shows the cities as plain dots after Verifica (used by Capitali) and a `targets()` function returning `{id, name, cx, cy}` items; the geometry it refers to must exist in `data.js` and be wired into the matching layer of `MAPS.eu`. Its labels go in `i18n.js` as `mode.<id>.label`, `.tray`, `.subtitle`, `.what` and `.help`, and its place names in `places`. New geometry is added in `tools/build_data.py`, never in `data.js`.
