# eugeo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static Europe geography quiz (rivers, seas, mountain ranges; Italian) at eugeo.giar.dev, cloned from chgeo, with geometry generated reproducibly from Natural Earth.

**Architecture:** Three served files (`index.html`, `i18n.js`, `data.js`) exactly like chgeo, no build step. `data.js` is emitted by `tools/build_data.py` (Python, pyshp + shapely + pyproj) from downloaded Natural Earth 10m shapefiles plus two hand-drawn polygons. The engine is chgeo's `index.html` with two new layers (`seas`, `ranges`), a `sea` kind and generic `parent` handling.

**Tech Stack:** HTML/CSS/vanilla JS (no deps); Python 3.12+ with pyshp, shapely, pyproj, pytest (dev only); GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-17-eugeo-design.md`

## Global Constraints

- No AI co-author lines in commits (owner rule). Commit messages: conventional prefix, imperative.
- Served site: no package manager, no bundler, no third-party scripts, no analytics or cookies. Ko-fi link stays a plain `<a>`.
- Data sources: Natural Earth 1:10m only, downloaded from `https://naciscdn.org/naturalearth/10m/<physical|cultural>/<name>.zip`; plus `tools/handdrawn.geojson` (CC0). Nothing else.
- `data.js` is generated; never hand-edited. It must be `window.GEO = <JSON>;` so tests can parse it with `json.loads`.
- Target ID prefixes: `c:` country, `t:` town, `r:` river, `s:` sea, `m:` range. IDs derive from Italian names with spaces and accents removed (`s:MareDelNord`, `m:MassiccioCentrale`, `m:AlpiDinariche`, `m:CordiglieraCantabrica`, `m:MontiScandinavi`, `m:MontiUrali`, `s:Mediterraneo`, `s:Ligure`, `s:Tirreno`, `s:Adriatico`, `s:Ionio`, `s:Egeo`, `s:Baltico`, `s:Nero`, `s:Caspio`, `s:Atlantico`, `r:Tago`, `r:Ebro`, `r:Loira`, `r:Tamigi`, `r:Rodano`, `r:Po`, `r:Reno`, `r:Elba`, `r:Danubio`, `r:Vistola`, `r:Dnepr`, `r:Don`, `r:Volga`, `m:SierraNevada`, `m:Pirenei`, `m:Alpi`, `m:Appennino`, `m:Balcani`, `m:Carpazi`, `m:Caucaso`).
- Canvas `w: 1000, h: 800`; projection EPSG:3035; extent window lon −25..70, lat 33..72 (tunable, but all 36 targets must be fully inside).
- Never hard-code user-facing text in `index.html`; every string goes through `i18n.js`.
- Creating the GitHub repo, enabling Pages and pushing require the owner's explicit confirmation at that step.
- Owner's model preference: subagents run on Opus.

## Review Focus

1. Tapping a Mediterranean sub-sea while the "Mar Mediterraneo" card is selected must place the card on the sub-sea, not the basin, and Verifica must then mark it wrong with a red chip; this is the only way the parent rule can confuse a child. (Test: Task 8 step 4, manual checklist item c.)
2. A sea polygon that Natural Earth has inside the extent but that is in no merge table (e.g. Sea of Marmara) must render as plain water and be logged by the script, never silently dropped or silently merged. (Test: Task 4, `test_unmapped_seas_are_logged`.)
3. The 13 rivers must each be one continuous path even though Natural Earth stores them as several records (River + Lake Centerline, Tajo + Tejo, Rhein + Rhin + Rhine); a missing part shows as a broken line. (Test: Task 3, `test_each_river_has_all_parts`.)
4. The Urals and the Caspian sit at the eastern edge: the fit must not clip them. (Test: Task 6, `test_all_targets_inside_canvas`.)
5. With only one language, the language select must be hidden and `?lang=de` must fall back to Italian without errors. (Test: Task 8 manual checklist item f.)

### Task 2: Pipeline core (download, project, fit, path emit)

**Files:**
- Create: `tools/build_data.py`, `tools/test_build_data.py`

**Interfaces:**
- Produces (all in `tools/build_data.py`):
  - `NE_BASE = 'https://naciscdn.org/naturalearth/10m/'`; `DATASETS: dict[str, str]` mapping short name → `'physical/ne_10m_land'` etc. for: `land`, `countries`, `rivers`, `marine`, `regions`, `lakes`, `places`.
  - `fetch(name: str, cache: Path) -> Path`: downloads zip if absent, unzips into `cache/<ne_name>/`, returns the `.shp` path. Also returns version via `read_version(cache, name) -> str` (contents of `*.VERSION.txt`, stripped).
  - `read_shp(shp: Path) -> list[tuple[dict, BaseGeometry]]` (record dict with lower-cased keys, shapely geometry).
  - `W, H = 1000, 800`; `MARGIN = 16`; `WINDOW = (-25.0, 33.0, 70.0, 72.0)` (lon_min, lat_min, lon_max, lat_max).
  - `class Fit`: built by `Fit.from_window(window) -> Fit`; projects the window edge (sampled every 0.5°) with `pyproj.Transformer.from_crs('EPSG:4326','EPSG:3035', always_xy=True)`, takes its bbox, and computes `scale`, `ox`, `oy` so that the bbox fits in `(W-2*MARGIN) x (H-2*MARGIN)` centred. Methods: `project(geom) -> BaseGeometry` (lon/lat → canvas px, y down, via `shapely.ops.transform`), `clip(geom) -> BaseGeometry` (`shapely.clip_by_rect` to the projected window bbox, applied in EPSG:3035 before scaling), `to_canvas(geom) -> BaseGeometry` (= clip then project).
  - `to_path(geom, nd: int = 1) -> str`: SVG path, `M x y L x y … Z` per polygon ring (exterior and holes), `M … L …` per line part; coordinates rounded to `nd` decimals, no scientific notation.
  - `anchor(geom) -> tuple[float, float]`: `representative_point()` for polygons; for lines, the point at `interpolate(0.5, normalized=True)` of the longest part. Rounded to 1 decimal.
  - `simplify(geom, tol_km: float) -> BaseGeometry`: `geom.simplify(tol_km*1000, preserve_topology=True)` in EPSG:3035 metres.
